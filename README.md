# UNESENNYE CLIENT v1.3.3

**Автор:** KRa Tos (Константин)

## Носители

- SD-карта / пустая SD
- Кассета
- Диск
- **CD**
- **DVD**
- **DVD-R**

Quantity = ID плейлиста.

## Текстуры

```bat
pip install Pillow
python tools\generate_item_textures.py
```

Затем PNG/TGA → **PAA** в TexView2 → `data/textures/`.

См. `data/textures/README_TEXTURES.md`.
